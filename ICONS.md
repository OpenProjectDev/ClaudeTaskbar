# Icons

The source repository doesn't include third-party icon files: their license doesn't allow offering them for download. (The app's own icon, in `icon/`, was drawn for this project and is GPL like the rest.) The two marks in the settings window's About section are drawn from outlines in the source code (`settings_app/lib/ui/family_marks.dart`), adapted from these Flaticon icons and credited as their license asks, in the app's Licenses screen. They are the OpenProject family's marks and aren't offered for reuse.

Flaticon's address for an icon ends in its ID: `flaticon.com/free-icon/<name>_<id>`.
